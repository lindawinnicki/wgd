## Aim
This pipeline was created as part of a bioinformatics project course. Its primary objective is to identify duplicated segments within fungal genomes. The goal is to determine whether there has been a historical large-scale/whole-genome duplication (WGD) event in the species. 
This pipeline utilises the suite of tools `wgd v2` (GitHub: "https://github.com/heche-psb/wgd/tree/phylodating"). Most of the pipeline utilises default parameters, except for an adjusted collinearity threshold of 10 genes instead of 30, to better fit the high plasticity of fungal genomes.

## Data Availability
Raw genome data (CDS, protein, and GFF files) **are not included in this repository** due to file size. They were obtained from JGI (March 2026) and can be downloaded from https://mycocosm.jgi.doe.gov/mycocosm/home (account required):

- Auricularia subglabra TFB10046 SS-5 ( Project ID: 402897 )
- Exidia glandulosa HHB12029 Annotated Standard Draft ( Project ID: 1006905 )
- Calocera cornea v1.0

Place them under `Data/<sample>/` following the structure in samples.tsv before running the pipeline.

# Requirements
- `Conda` or `Mamba`
- `Snakemake` v9.21.1

# Setup
````bash 
git clone https://github.com/lindawinnicki/wgd
cd wgd
````

# Running the pipeline
In terminal, run:
````bash
snakemake --configfile config.yaml --use-conda -j <cores>
````
Set `-j` to the number of CPU cores available on your machine (check with `nproc`). Individual rule thread requests are set in `config.yaml` under `threads:`.

## Sample sheet
`samples.tsv` should contain the following columns: `sample`, `role`, `cds_fasta`, `aa_fasta`, `genome_fasta`, `gff`, `busco_lineage`, `gff_id_attr` and `gff_feature_type`.

# Configuration
All settings are found in "config.yaml", so edit it before running a new sample.
| Key | Description |
|-----|-------------|
| `samples` | Path to sample sheet "samples.tsv" |
| `outdir` | Output root directory |
| `species_tree` | Species tree in Newick format. Node order must match `samples.tsv` |
| `dmd` | Extra flags for "wgd dmd" (empty = defaults) |
| `ksd` | If `true`, also runs the `--pairwise` variant |
| `syn` | Intraspecific synteny params. |
| `inter_syn`| Same as above, but for interspecific synteny |
| `viz` | Toggle which interspecific plots get generated |
## Specific Sample Settings
| Key | Description |
|-----|-------------|
| `clean_headers.<sample>` | sed regex to strip JGI-style headers. Leave `""` if no cleaning needed |
| `inter_prefix.<sample>` | Prefix added to gene names in interspecific CDS to avoid collisions (leave `""` for the outgroup, or any sample with no name clashes) |
